# Project 2 - Student Management REST API

## Technologies
- Java 17
- Spring Boot
- Maven

## Features
- GET all students
- GET student by ID
- POST create student
- PUT update student
- DELETE student
- Request validation using @Valid
- Global exception handling
- ResponseEntity with appropriate HTTP status codes

## API Endpoints

GET /student

GET /student/{id}

POST /student

PUT /student/{id}

DELETE /student/{id}
